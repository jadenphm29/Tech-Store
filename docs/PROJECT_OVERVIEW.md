# Tech Store — Project Overview

## Tên Dự Án
**Tech Store** — Hệ thống thương mại điện tử bán lẻ thiết bị công nghệ

## Mục Đích
Xây dựng một platform e-commerce chuyên bán các sản phẩm công nghệ cao cấp với giao diện thân thiện, tích hợp các tính năng quản lý kho và đơn hàng.

## Người Dùng Chính

### 1. Customer (Khách hàng)
- Duyệt, tìm kiếm sản phẩm
- Thêm vào giỏ hàng
- Đặt hàng
- Quản lý đơn hàng
- Đánh giá sản phẩm

### 2. Administrator (Quản trị viên)
- Quản lý sản phẩm, danh mục, thương hiệu
- Quản lý tồn kho
- Quản lý đơn hàng
- Quản lý khách hàng
- Xem thống kê

## Công Nghệ Chính
- **Backend:** Java 27, Spring Boot 4.1.2
- **Frontend:** HTML5, CSS3, Vanilla JavaScript, Thymeleaf
- **Database:** MySQL 8.0.46
- **Build:** Maven 3.9.16
